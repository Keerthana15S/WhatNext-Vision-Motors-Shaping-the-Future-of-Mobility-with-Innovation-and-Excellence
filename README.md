# WhatNext Vision Motors 🚗

## Project Overview

WhatNext Vision Motors is a Salesforce-based vehicle management system developed to manage vehicles, dealers, customers, orders, test drives, and service requests efficiently.

## Features

- 🚗 Vehicle management
- 🏢 Dealer management
- 👤 Customer management
- 🛒 Vehicle order management
- 🚘 Test drive booking
- 🔧 Vehicle service request management
- 📦 Stock availability tracking
- 📧 Email notifications
- ⚙️ Automated order status updates

## Salesforce Technologies Used

- Salesforce Custom Objects
- Custom Fields
- Relationships
- Validation Rules
- Flows
- Apex
- Apex Triggers
- Batch Apex
- Lightning App

## Main Objects

- Vehicle__c
- Vehicle_Dealer__c
- Vehicle_Customer__c
- Vehicle_Order__c
- Vehicle_Test_Drive__c
- Vehicle_Service_Request__c

## Project Goal

The main goal of this project is to simplify vehicle sales and management by connecting customers, vehicles, dealers, orders, test drives, and service requests in one Salesforce application.
